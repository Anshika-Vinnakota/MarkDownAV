# Markdown Learning Journal

## Overview

A learning journal for students practicing technical communication with GitHub Markdown.

## Features

- Organize daily learning with headings.
- Track practice tasks with checkboxes.
- Explain progress using mathematical expressions.

## Usage
From the repository folder, display the journal in a terminal with this command. On Windows PowerShell, use `Get-Content day-1.md` instead.

```bash
cat day-1.md
```
For formatted reading, open [the journal](../day-1.md) on GitHub and select Preview when editing. Check or uncheck tasks by editing their Markdown and committing your changes.

## Prerequisites

Use a web browser to read the journal on GitHub. For a local copy, install Git and a text editor. A GitHub account with repository access is required to contribute.

## Installation

Run these commands in a terminal to download this repository, then enter its folder:

```bash
git clone https://github.com/YOUR-USERNAME/skills-communicate-using-markdown.git
cd skills-communicate-using-markdown
```

Open `day-1.md` in your editor to confirm the journal is present. No build or dependency installation is required.

## Expected output

The terminal displays the source Markdown. Your title may differ from this shortened example:

```text
# Daily Learning

## Morning Planning
```

On GitHub, the same headings appear at different sizes and task markers become checkboxes.
